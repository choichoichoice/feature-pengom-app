# 앱에 넣은 글꼴

인터넷 없이도 같은 모양으로 보이도록 글꼴 파일을 앱 안에 넣는다 (Google Fonts를 부르지 않음).

| 파일 | 원본 | 용도 |
|---|---|---|
| `jua.woff2` | Jua Regular (google/fonts, OFL) | 큰 숫자·제목 |
| `pengomsans-400/500/600/700.woff2` | IBM Plex Sans KR Regular/Medium/SemiBold/Bold (google/fonts, OFL) | 본문 |

- 글자 범위를 줄였다: 기본 영문·숫자·기호 + 자주 쓰는 한글 2,350자(KS X 1001) + 앱 화면에 쓰인 모든 글자.
  목록에 없는 드문 글자는 휴대폰 기본 글꼴로 보인다.
- 줄인 글꼴은 수정본이라, OFL 규정에 따라 예약 이름("Plex")을 쓰지 않고 `PengomSans`, `PengomDisplay`라는 이름으로 바꿨다.
- 라이선스: `OFL-Jua.txt`, `OFL-IBMPlexSansKR.txt`
